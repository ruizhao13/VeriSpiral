# Paper Ingestion

## Trigger

Use when a new primary source must enter the research system.

## Workflow

1. Record source identity and close-read status.
2. Extract the problem, observation model, loss, and output.
3. Record assumptions before interpreting them.
4. Convert each main result into a scoped claim card.
5. Extract proof tools, limitations, and transferable mechanisms.
6. Link the source to active candidates without asserting novelty.

## Validation

- Every promoted claim has a source location.
- Metadata-only records are visibly labeled.
- Source claims and analyst inferences are separated.
